# MyPetTravel 🐾

A personal assistant for travelling with your pet. MyPetTravel helps you track, plan and organise everything — from documentation and vaccinations to timelines and tasks — so nothing falls through the cracks when you travel with your animal.

Built from real experience relocating internationally with a dog.

## Features
- 🗂 Document tracker — keep all pet travel docs in one place
- ✅ Task & todo management — know what needs doing and when
- 📅 Timeline & calendar — visualise your travel prep at a glance
- 🐶 Pet profile setup — store your pet's details once, use everywhere
- 🤖 Ask Claude — built-in AI assistant for pet travel questions
- 🔐 Auth & user accounts via Supabase

## Tech Stack
- React Native + Expo
- Supabase (Auth + Postgres)
- Zustand (state management)
- Custom rule engine for travel requirement logic
